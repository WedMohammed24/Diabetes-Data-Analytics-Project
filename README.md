# 🧬 Pima Indians Diabetes Dataset: Exploratory Data Analysis & Biomedical Cleaning

This project is the final deliverable for the **Data Science and Bioinformatics Bootcamp** (supervised by *Genome X Newtech*). It focuses on exploratory data analysis (EDA) and data preprocessing on real-world medical data to predict and analyze risk factors associated with Type 2 Diabetes.

---

## 📌 Project Overview
- **Dataset:** Pima Indians Diabetes Dataset (768 records, 9 biomarkers).
- **Core Objective:** Clean medical data, handle missing/zero values, and extract clinical insights using statistical analysis and data visualization.
- **Tools & Libraries:** Python, Pandas, NumPy, Seaborn, Matplotlib, Google Colab.

---

## 🛠️ Methodology & Steps
1. **Data Cleaning & Imputation:** Identified impossible zero-values in vital biomarkers (Glucose, Blood Pressure, BMI, Insulin, Skin Thickness) and resolved them using **Mean Imputation** to preserve sample size.
2. **Descriptive Statistics:** Extracted comprehensive statistical summaries (`df.describe()`) to analyze distributions and central tendencies.
3. **Correlation Analysis:** Generated and interpreted correlation heatmaps to identify primary risk factors (Glucose and BMI show the highest direct correlation with diabetes outcomes).
4. **Data Visualization:** Built distribution plots to illustrate class balances and clinical patterns.

---

## 📂 Deliverables
- **Google Colab Notebook:** Contains the full data pipeline, cleaning process, and visualization code.
- **Professional PDF Report:** An 8-page structured decision-maker report designed via Canva.
